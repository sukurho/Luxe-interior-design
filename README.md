🏡 Luxe Interior Design Website

A modern, responsive interior design website built with HTML, CSS, and JavaScript. The website showcases interior design services, featured projects, company information, and contact details while providing a clean user experience across desktop, tablet, and mobile devices.

⸻

📌 Project Overview

Luxe Interior Design is a professional website designed for an interior design company. It allows visitors to explore the company’s services, portfolio, and expertise while providing an easy way to contact the business.

⸻

✨ Features

* Responsive design for Desktop, Tablet, and Mobile
* Modern and elegant user interface
* Fixed navigation bar
* Mobile navigation menu
* Dark Mode toggle
* Hero sections with background images
* Services section
* Featured Projects
* Why Choose Us section
* Design Process
* Testimonials
* Call-to-Action section
* Brand Partners section
* Contact page with map and contact form
* Footer with social media links

⸻

🛠 Technologies Used

* HTML5
* CSS3
* JavaScript
* Font Awesome Icons
* Google Fonts (Playfair Display & Poppins)

📱 Responsive Design

The website is fully responsive and optimized for:

* Desktop
* Tablet
* Mobile Phones

Media queries were used to ensure the layout adapts smoothly to different screen sizes.

⸻

🌙 Dark Mode

The website includes a Dark Mode feature that allows users to switch between light and dark themes for a better viewing experience.

⸻

🚀 How to Run the Project

1. Download or clone the repository.
2. Open the project folder.
3. Open index.html in your web browser.

Or run it using the Live Server extension in Visual Studio Code.
